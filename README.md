# صون النعم - Saun Al Naam\n\n## مبادرة لمكافحة هدر الطعام في العراق\n\n### 📱 نظرة عامة\nتطبيق Flutter شامل يهدف إلى تقليل هدر الطعام وربط المطاعم والمتاجر بالأشخاص المحتاجين والمتطوعين من خلال منصة رقمية آمنة وسهلة الاستخدام.\n\n### ✨ المميزات الرئيسية\n\n#### 👥 للمستخدمين العاديين\n- 🔍 البحث عن الطعام المتاح بالقرب منهم\n- 📍 تحديد الموقع الجغرافي\n- 📱 تقديم طلبات الطعام\n- ⭐ تقييم المطاعم والمتطوعين\n- 📋 سجل الطلبات والاستفادات\n- 📄 شهادات شرعية للاستفادة\n\n#### 🍽️ للمطاعم والمتاجر\n- ➕ إضافة الطعام الفائض\n- 📊 إدارة الطلبات والعروض\n- 📈 إحصائيات المساهمات\n- ✅ التحقق والموثق الشرعي\n- 🏆 شهادات المساهمة الخيرية\n\n#### 🤝 للمتطوعين\n- 📦 عرض الطلبات المتاحة للتوصيل\n- 🗺️ تتبع المسارات (GPS)\n- 📍 إدارة التوصيلات\n- ⭐ نظام التقييم والشهادات\n- 📊 سجل الأنشطة والساعات\n\n#### 👨‍💼 للإدارة\n- 📊 لوحة تحكم شاملة\n- 📈 إحصائيات وتقارير\n- ✔️ التحقق من الحسابات\n- 🔐 إدارة الأمان والسلامة\n- 📋 إدارة الشكاوى\n\n### 🛠️ المتطلبات التقنية\n\n```bash\nFlutter >= 3.0.0\nDart >= 3.0.0\nAndroid SDK >= 21\niOS >= 12.0\n```\n\n### 📦 المكتبات الرئيسية\n\n- **Firebase**: للمصادقة وقاعدة البيانات\n- **Google Maps**: لتحديد المواقع\n- **Provider**: لإدارة الحالة\n- **Geolocator**: للموقع الجغرافي\n- **Image Picker**: لرفع الصور\n\n### 🚀 البدء السريع\n\n#### 1. استنساخ المشروع\n```bash\ngit clone https://github.com/omaralshimarey-lang/saun_al_naam.git\ncd saun_al_naam\n```\n\n#### 2. تثبيت المتطلبات\n```bash\nflutter pub get\n```\n\n#### 3. إعداد Firebase\n- أنشئ مشروع Firebase جديد\n- قم بتحميل ملف `google-services.json` (Android)\n- قم بتحميل ملف `GoogleService-Info.plist` (iOS)\n- أنشئ ملف `firebase_options.dart`\n\n#### 4. تشغيل التطبيق\n```bash\nflutter run\n```\n\n### 📂 هيكل المشروع\n\n```\nsaun_al_naam/\n├── lib/\n│   ├── main.dart\n│
